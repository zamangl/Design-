# StudioCanvas — Online Design Maker

A responsive, static website starter with 110 editable design templates across 10 categories.

## Features
- 110 template cards and category filters
- Search templates
- Live editor for heading, subtitle, label, background/text colors, and font
- Download the customized artwork as a PNG
- Mobile responsive
- No API key or build step required

## Deploy to GitHub and Vercel
1. Create a new repository on https://github.com (for example `studiocanvas-design-maker`).
2. Upload `index.html` and `README.md` to the repository root. GitHub's browser upload is documented at https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file
3. Go to https://vercel.com and sign in with GitHub.
4. Select **Add New → Project**, import your repository, and deploy. Vercel will serve this static `index.html` automatically.
5. Open the generated `.vercel.app` URL.

Official Vercel guide: https://vercel.com/docs/git/vercel-for-github

## Important
This is a front-end template editor starter. It doesn't include accounts, cloud storage, payment processing, or AI image generation. Those features require additional services/backend work.
